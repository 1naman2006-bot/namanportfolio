# Videos

Put your showreel here as `showreel.mp4` (H.264 + AAC, 1080p, ideally under 60 MB).
The file name/path is set in `src/config/site.js` → `showreel.src`.

Prefer YouTube or Vimeo for a long or very large reel: paste its link into `showreel.embed` instead.
Until a video exists, the homepage shows a designed 'coming soon' panel with a contact button.
