# Premiere Pro projects

Cinematic edits, music videos, beat-sync edits, commercials, social reels and colour grading.

- Thumbnail: JPG/WebP 16:10 (1600 × 1000 px); a strong frame from the edit.
- Full video: MP4 (H.264, AAC) under ~40 MB, or a YouTube/Vimeo link in `video`. Large files are better on YouTube/Vimeo.
- Add `duration: '1:20'` so it shows on the card.
- Reference files as `/projects/premiere-pro/<file>` with `category: 'premiere-pro'`.
