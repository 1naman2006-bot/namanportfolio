# Photoshop projects

Posters, ads, photo manipulation, retouching, compositing and promotional graphics.

- Thumbnail: JPG or WebP, 4:5 portrait works best (e.g. 1600 × 2000 px), under ~500 KB.
- Gallery images: JPG/WebP up to 2400 px on the long edge.
- Before/after pairs: same size and crop, e.g. `poster-before.jpg` + `poster-after.jpg`.
- Reference files as `/projects/photoshop/<file>` in `src/data/projects.js` with `category: 'photoshop'`.
